# TV Wall Art Package

Two **backlit acrylic art panels** that hang either side of a TV, with **4 artwork designs** to choose from.
Everything needed to **print, build, hang and light** them is here.

![Planet horizon, by day and lit](05%20-%20PREVIEWS%20%28what%20it%20should%20look%20like%29/1%20-%20Planet%20horizon%20-%20day%20and%20lit.jpg)

## Start here

1. Click the green **Code** button above, then **Download ZIP**. Unzip it.
2. Open **`00 - START HERE.pdf`**. It says which folder is for whom.

| If you are... | Open this folder | Read first |
|---|---|---|
| The **printer** | `01 - FOR THE PRINTER` | `00 - PRINTER BRIEF.pdf` |
| The **box maker** | `02 - FOR THE BOX MAKER` | `00 - BUILD SHEET.pdf` |
| The **installer** | `03 - FOR THE INSTALLER` | `00 - INSTALL SHEET.pdf` |
| The **LED / electrics** person | `04 - FOR THE LED SETUP` | `00 - LED AND WLED SETUP.pdf` |
| Anyone | `05 - PREVIEWS` | the video and pictures |

## Print files (printers only)

The 900 dpi print files are too big for the folder above, so they are on the
**[Releases page](../../releases)**, with one release per design. Each design has
**2 panels x 2 sheets**, and each sheet is a separate zip, so you only download what you print:

| Zip name contains | Sheet |
|---|---|
| `LEFT-panel_SHEET-1-clear` | Left panel, clear acrylic 4 mm |
| `LEFT-panel_SHEET-2-opal` | Left panel, opal acrylic 3 mm |
| `RIGHT-panel_SHEET-1-clear` | Right panel, clear acrylic 4 mm |
| `RIGHT-panel_SHEET-2-opal` | Right panel, opal acrylic 3 mm |

Unzip everything for one design into the same place. The folders rebuild themselves, and each one
contains its own picture guide (`00 - HOW TO PRINT`).
